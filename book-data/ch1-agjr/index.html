Colombia state-capacity data pack

Public Economics for Developing Countries, Chapter 1, Evidence Spotlight "State capacity in Colombia: an old map read next door" and Data problem 27.

Two plain CSV files, values unchanged, re-exported from the replication file of Acemoglu, García-Jimeno and Robinson, "State Capacity and Economic Development: A Network Approach," American Economic Review 105(8), 2015. Column names follow the study's data dictionary. Stata, R, Python and MATLAB all read them. Cite the article, not this pack. The authors' own package is at sherafghanasad.com/go/ch1-agjr.

  • ch1-agjr-data.zip (all three files)
  • agjr-colombia.csv (one row per municipality, 1,019 rows)
  • agjr-neighbors.csv (one row per pair of neighbors, 5,592 rows)
  • README.txt (every column, and every check value in the chapter)
