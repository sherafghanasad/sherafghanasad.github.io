Raskin identification cards data pack

Public Economics for Developing Countries, Chapter 3, Evidence Spotlight "A card for a rice subsidy that leaked".

One plain CSV file, values unchanged, cut from the replication package of Banerjee, Hanna, Kyle, Olken and Sumarto, "Tangible Information and Citizen Empowerment: Identification Cards and Food Subsidy Programs in Indonesia," Journal of Political Economy 126(2), 2018. It holds the households and columns the chapter's Rebuild-it steps use. Stata, R, Python and Excel all read it. Cite the article, not this pack. The authors' full package is linked from Benjamin Olken's web page at MIT.

  • ch3-raskin-data.zip (the CSV file and the README)
  • raskin-course-copy.csv (one row per household per survey, 9,312 rows)
  • README.txt (every column, and the chapter's check values)
